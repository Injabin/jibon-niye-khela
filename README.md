# Jibon Niye Khela

A free, browser-based life-simulation game where every tap has weight. 

## Tech Stack
- Next.js 14+ (App Router)
- TypeScript (Strict mode)
- Tailwind CSS
- Zustand
- Framer Motion
- Howler.js
- Vitest / Playwright

## Local Setup
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev` to start the development server

## How to run tests
- Unit/Logic tests: `npm run test`
- E2E smoke tests: `npm run test:e2e`
- Typecheck: `npm run typecheck`
- Lint: `npm run lint`
